ЧТО ДЕЛАЕТ ПРОГРАММА
Читает пакет задачи (ZIP-архив или папку) и выводит данные о ней:
название, лимиты времени и памяти, проверяющую программу, группы тестов, баллы, сами тесты
и другие сведения, которые описаны в формате пакета.


КАК ЗАПУСТИТЬ

1. Нужен .NET SDK 8.0 или новее. Проверить: dotnet --version
2. Собрать программу:
     Windows:     build.bat
     Linux/macOS: ./build.sh
   Готовая программа появится в папке build (файл Program.exe).
3. Запуск:
     build\Program.exe [FORMAT] [PACKAGE] [--brief]
   FORMAT   KRSU | CATS | PCMS2 | EJUDGE
   PACKAGE  путь к ZIP-архиву пакета (можно и к распакованной папке)
   --brief  короткий вывод (без списка тестов и текста условия)


АРХИТЕКТУРА И SOLID (src/TaskParser)
Папки:
  Model    единая модель задачи (ProblemInfo, TestCase, TestGroup), интерфейс IProblemParser
  Pkg      доступ к файлам пакета (IPackageSource): ZIP и папка
  Parsers  по папке на формат: Krsu, Cats, Pcms2 (2 варианта), Ejudge
  Output   вывод (IProblemPrinter): консоль
  App      Application (сценарий), ParserRegistry (реестр форматов), Program (сборка объектов)
  Util     разбор единиц, шаблонов имён файлов, безопасное чтение XML

S - у каждого класса одна задача: чтение файлов, разбор формата, хранение данных и вывод разделены.
O - новый формат = новый класс IProblemParser + одна строка Register(...) в Program, остальное не меняется.
L - любая реализация IPackageSource (ZIP, папка) и IProblemParser взаимозаменяема.
I - интерфейсы узкие: читать пакет, разобрать, вывести, открыть пакет, вариант файла PCMS2.
D - Application зависит только от интерфейсов; конкретные классы создаются в одном месте, Program.Main.
